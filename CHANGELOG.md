# Changelog

All notable changes to this package are documented here.

## 0.1.0 - 2026-09-06

- Initial public release of `pi-bash-handoff`.
- Automatic foreground-to-background handoff for the canonical `bash` tool.
- Minimal `process(list|peek|send|kill)` control surface with pipe stdin.
- Owner-only disk logs, bounded model output, and exactly-once completion
  follow-ups.
- Project-local `.pi/background-processes.json` configuration.
